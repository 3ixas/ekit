# EKit changes

## Preparation baseline

EKit preserves the active personal workflows, candidate and paused lifecycles, shared instructions, and separate Claude Code plugin. Public preparation adds portable provenance/notices, independently sourced artifact and analytical guidance, and browser-download/selective-review instructions.

This preparation source is not a published release. The private archive retains the earlier curation history; new maintained changes can be recorded here after the reviewed public baseline is established.
