# Skill Review

## Outcome

A complete keep, import, adapt, merge, defer, pause, or retire decision with evidence.

## Method

1. Pin and inventory every in-scope entrypoint and asset; group them by capability and compare each with current owners.
2. Assess added behaviour, routing, authority, dependencies, quality, learning boundary, licence, and maintenance. For repository-scale intake, use [the admission rubric](references/admission-rubric.md) to make those comparisons explicit.
3. Forward-test when risk warrants. Record observed behaviour and any untested or unavailable evidence separately from expectations.
4. Record a disposition and rationale for every entrypoint. Done when the inventory reconciles with the disposition record and any decision requiring Elias is explicit; an assessment does not apply those decisions.

## Boundaries

Assessment is read-only by default. Popularity and installation do not establish admission.
