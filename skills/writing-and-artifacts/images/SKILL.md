# Images

## Outcome

A generated image that matches composition, subject, style, constraints, and intended use.

## Method

Clarify output and aspect ratio from context; use all required reference images; write a concrete visual prompt; generate or edit through ImageGen; inspect the returned image; compare identity, layout, text, artifacts, and requested changes; iterate only on observed gaps.

## Brand and placement handoff

For product assets, read the approved project `DESIGN.md` and available brand/reference assets before generating. Carry its palette, identity, visual treatment, subject, composition, crop/negative space, aspect ratio, transparency and intended placement into one concrete brief. Record any missing constraint as an assumption rather than inventing a new direction. Keep related assets consistent through shared references and edit the selected direction instead of rerolling unrelated styles. Inspect the result at its intended placement and size, including contrast behind overlaid content; leave critical interface text to the product UI. If identity or direction is unsettled, return that decision to `interface-design`.

This method uses the existing image-generation capability. It does not require uploading a brand kit to Limora, opening an account or buying a subscription.

## Boundaries

Interface composition belongs to interface-design and charts to data-visualization. Do not use image generation to typeset critical text.
