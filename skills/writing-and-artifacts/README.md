# Writing And Artifacts

Create strong prose and correctly rendered documents, PDFs, spreadsheets, slides, and images.

| Skill | Invocation | Purpose |
|---|---|---|
| `documents` | automatic | Create, edit, inspect, or redline Word documents when pagination, styles, comments, tracked changes, or rendered layout matter. |
| `images` | automatic | Generate or edit raster images from a clear brief and supplied references, then inspect the actual result against the requested target. |
| `pdf` | automatic | Read, create, transform, inspect, or fill PDFs with extraction and rendered-page verification. |
| `slides` | automatic | Create, revise, or inspect presentation decks with a coherent narrative, slide-specific composition, and rendered overflow checks. |
| `spreadsheets` | automatic | Create, edit, analyze, or verify spreadsheet files with formulas, tables, charts, formatting, and recalculation evidence. |
| `writing` | automatic | Develop, draft, edit, review, humanize, or finalize emails, essays, posts, technical prose, and other writing while preserving facts, voice, audience, and uncertainty. |
| `writing-for-agents` | supporting | Write or revise AGENTS.md, SKILL.md, prompts, and agent-consumed documents so routing, steps, evidence, and completion remain clear and economical. |

## Common paths

- Prose: `writing`. File-format construction then routes to the matching artifact skill.
- Agent instructions: `writing-for-agents`, usually through `skill-authoring`.
