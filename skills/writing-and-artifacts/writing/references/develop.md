# Develop

Use this mode before drafting when the thinking is incomplete.

## Establish the job

Identify the reader, the change the writing should create, the form, the author’s position, and the evidence available. A useful one-line brief is:

> After reading this, **[reader]** should **[understand, feel, decide, or do]** because **[central reason]**.

Ask only for information that cannot be found in the supplied material. Keep uncertain facts visibly uncertain. Never manufacture a personal story, opinion, result, quote, or source to fill a gap.

## Build the argument

Work from claims and evidence before headings or polished sentences:

1. Write the central claim in plain language.
2. List the few supporting claims the reader must accept.
3. Attach evidence, examples, or reasoning to each claim.
4. Record the strongest objection, ambiguity, or alternative.
5. Remove points that do not advance the intended reader action.

Prefer a narrow, defensible angle over broad coverage. If the material supports multiple viable angles, show the alternatives and recommend one using the reader and purpose as criteria.

## Shape the piece

Choose an order that matches how the reader decides: context then proposal, problem then consequence then response, claim then evidence, or chronological sequence when time is the subject. Give each section one job. End once the intended job is complete rather than adding a generic recap.

The output of this mode can be a brief, argument map, evidence map, or outline. Do not silently expand it into a finished draft when the user asked to develop the thinking.
