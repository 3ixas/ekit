# Edit

Edit the existing text toward its stated purpose while preserving facts, intent, and recognizable voice.

## Work from large to small

1. **Purpose and audience:** Does the piece ask the right thing of the right reader?
2. **Substance:** Are claims supported, qualifications honest, and key facts present?
3. **Structure:** Does each section advance the piece, in the order the reader needs?
4. **Paragraphs and sentences:** Remove repetition, buried leads, vague links, and avoidable complexity.
5. **Words and mechanics:** Tighten diction, rhythm, grammar, punctuation, and formatting.

Do not polish a sentence that should be removed. Do not turn a light edit into a wholesale rewrite unless the draft cannot meet its purpose otherwise; when the distinction matters, explain the needed scope.

## Preserve what must survive

Keep code, commands, identifiers, paths, quotes, error text, citations, dates, numerical values, and legal or contractual wording exact unless changing them is part of the request. Do not strengthen certainty or causality. If a correction changes meaning, flag it.

## Return a useful result

For a normal edit, return clean copy first. For a consequential edit, briefly call out material changes and unresolved questions. Use tracked changes or a compact before/after only when the user needs to inspect the editorial decisions.
