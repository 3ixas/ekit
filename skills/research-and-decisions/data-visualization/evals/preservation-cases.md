# Chart preservation cases

Use labelled disposable data and inspect real rendered files or UI. Source and rendered checks establish different claims.

- Render the 82% versus 18% aggregate from the analytical mix case as aligned magnitude bars starting at zero, with numerator/denominator and segment context. A truncated baseline or unsupported deterioration headline fails.
- Show Jan=40, Feb=unknown, Mar=45 without converting February to zero or implying a measured connecting segment through the missing month.
- Display negative, zero and positive values without hiding signs. Refuse a log-axis encoding that cannot represent the reviewed data unless a defensible alternative is explicit.
- Show the mean interval from the analytical case with its method and level; preserve asymmetric bounds in a separate case. A filtered subgroup cannot reuse the aggregate's interval.
- For long names and multiple series, inspect intended wide and narrow sizes, grayscale and the requested export. Essential labels, signs, bounds and notes must survive. Colour differences alone are insufficient; provide redundant names/shapes/line patterns and a readable exact-value alternative.
- Deliver a short chart description and a meaningful longer description or data table. A rendered image does not prove a screen-reader path or an accessible PDF.
- For an interactive dashboard, change its main filter and check chart rows, denominator, bounds, annotations and exported values against the same selection. Exercise keyboard/touch and empty/error states on the actual surface. Report unavailable UI checks instead of claiming that a static image passed them.
- If the chosen renderer, browser or export tool is missing, identify the exact missing capability and produce only a supported output; do not silently import a proprietary runtime, publish externally or claim verification from a successful build alone.

Record actual dimensions, source values, output identities, inspections, defects/fixes and unperformed checks. Have an independent reviewer inspect both the chart's statistical interpretation and its rendered presentation. A finite fixture set preserves representative outcomes; it is not a claim of universal behaviour parity.
