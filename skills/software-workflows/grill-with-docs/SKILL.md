name: grill-with-docs
description: Clarify nontrivial software work through exhaustive questions and repository evidence, then preserve agreed scope, domain terms, and consequential decisions in project documents. Use when product behaviour is not settled enough to implement; use grilling for other domains.
---

Load the `grilling` and `domain-modeling` skills and follow both for the whole session. Use the Skill tool where the host has one; otherwise read each installed `SKILL.md` directly. Use [the scope contract](references/scope-contract.md) for what the settled scope must cover and where to write it.

Apply `grilling`'s collaborative exploration within the existing rounds: explain why consequential questions about behavior, states, interfaces, or failure recovery matter, using actual repository evidence and concrete cases. Develop the user's reasoning and make useful investigation patterns visible without adding a separate teaching phase. Preserve decisions, rationale, evidence, and open assumptions in project documents; keep the brief reusable-thinking reflection in the conversation.
