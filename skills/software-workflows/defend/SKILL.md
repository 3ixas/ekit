# Defend

## Outcome

Elias can explain the change, justify the important decisions, and identify its evidence and limits.

## Method

Inspect the actual work; ask one Explain question at a time; hint, retry, teach, and recheck gaps; Challenge alternatives, edges, failure modes, and evidence; ask for a concise Defence. On a defend-only request, report a real defect and ask whether to fix it; route an authorized correction to `implement` or `debug` and offer `learn` for substantial study.

Read and follow [references/three-phase-defence.md](references/three-phase-defence.md). Preserve the interactive sequence: ask one question, wait for Elias's answer, then respond.

## Boundaries

This is an optional learning check, not a delivery gate or scored quiz. Create a note only when requested.
