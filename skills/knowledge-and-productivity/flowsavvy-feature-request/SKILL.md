# Flowsavvy Feature Request

## Outcome

Paste-ready British-English content for idea, motivating situation, and current workaround.

## Method

1. Extract the user problem, desired behaviour, boundaries, example, motivating situation, and actual workaround. Separate the desired outcome from a speculative UI solution. Ask only when missing information prevents a truthful field.
2. Return three paste-ready fields in order: **Idea**, **Motivating situation**, and **Current workaround**. Preserve FlowSavvy terms and supplied facts; do not add introductory commentary.
3. Check that every claimed experience and workaround came from the user. Mark an unknown workaround honestly rather than inventing one.

## Boundaries

Do not invent frequency, urgency, internals, emotions, or a workaround the user did not provide.
