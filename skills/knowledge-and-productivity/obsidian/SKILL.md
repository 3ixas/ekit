# Obsidian

## Outcome

A focused knowledge operation that preserves Personal Knowledge structure, links, privacy, and authorship.

## Method

1. Read current vault AGENTS/config and locate the relevant notes. Bound retrieval to the request; personal facts belong to Personal Knowledge and project truth to project files.
2. Read [the vault operation contract](references/vault-operation-contract.md) before broad retrieval, structural changes, or persistence. Preserve exact personal wording unless rewriting is requested.
3. Apply the authorised scoped change, previewing consequential structural changes first. Read [formats and CLI](references/formats-and-cli.md) only when Markdown, Bases, Canvas, or command details matter.
4. Re-read changed sections and validate affected links and structure. Report what was retrieved, proposed, or saved, including any unresolved limitation.

## Personal direction and commitment reviews

For a goal, life-direction, current-focus or commitment check, read [the review routing contract](references/commitment-reviews.md). Load the live vault's configuration, active planning page and review guide before questions; use their current model and task provider. Do not reconstruct a remembered goal hierarchy. This branch owns the reflection and durable record; task or Calendar mutations remain separately authorised provider actions.

## Personal planning

For “review my long-term direction”, “review my current focus”, “plan next week” or “plan tomorrow”, use [the planning workflow](references/personal-planning.md). Resolve the live operating manual, current focus, standing defaults and relevant weekly plan; disclose any provider transition before relying on task evidence. Help choose and reduce work, then perform requested bookkeeping. The user chooses commitments and working times. Do not automatically create a timetable, roll unfinished work forward, or reopen higher-level decisions during ordinary day planning.

## Boundaries

Exclude employer secrets and unrelated private material. A direct natural-language instruction to create or update a resolved note authorizes that scoped write; preview only consequential structural changes. Do not revive automatic LLM Wiki ingestion or broad git staging.
