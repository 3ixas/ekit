# Dinner Decider

## Outcome

Two or three suitable choices followed by a practical UK-format recipe for the selected meal.

## Method

1. Apply the standing no-pork and no-known-allergy defaults, incorporating any current updates the user supplies. Ask only for missing current constraints and specialist-equipment information that materially affects the choices.
2. Research credible recipes with Exa. Return two or three varied choices with source links, fit, and timing; wait for the user to select one.
3. Return one exact two-serving recipe in UK units, with equipment, ingredients, sequential method, food safety, and source links. Check that quantities, equipment, timing, and method agree.

## Boundaries

Files, images, and cook-along are optional on request. If Exa is unavailable, preserve intake and stop before claiming researched recommendations.
