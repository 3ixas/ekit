# Nextjs

## Outcome

A Next.js implementation with explicit rendering and cache semantics.

## Method

Inspect package versions and configuration; choose server or client boundaries deliberately; make data freshness and invalidation explicit; preserve routing, metadata, error, loading, and streaming states; use official codemods and migration notes for upgrades; verify production build and runtime behaviour.

## Boundaries

Do not rely on remembered framework behaviour when current official documentation is available.
