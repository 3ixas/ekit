# Shadcn

## Outcome

Project-owned component code integrated with the existing tokens and interaction contract.

## Method

Inspect components.json, framework, aliases, theme, and installed primitives; search the current registry; add only selected components; preserve local modifications; compose semantics and states; verify keyboard, responsive, and rendered behaviour.

## Boundaries

Interface-design chooses whether and which component fits. Do not overwrite project components blindly.
