# React Native

## Outcome

A mobile implementation that behaves well on the target platforms and devices.

## Method

Inspect Expo/RN versions and native dependencies; use platform primitives and established navigation; virtualize real lists; avoid JS-thread animation work; test keyboard, safe areas, permissions, deep links, offline/error states, and device performance.

## Boundaries

Do not pretend web rendering proves native behaviour or add native dependencies without checking project constraints.
