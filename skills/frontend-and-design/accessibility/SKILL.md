# Accessibility

## Outcome

An interface whose relevant journeys work across the target access needs with manual and automated evidence.

## Method

Identify users, platform, and standards; inspect semantic structure and names; complete keyboard order, focus, errors, status, zoom/reflow, contrast, media alternatives, touch targets, and reduced motion; use automated scans to find candidates; manually exercise critical paths and report limits.

Read [accessibility review](references/accessibility-review.md) for journey-based implementation and audit coverage.

## Boundaries

A clean scanner is not a conformance claim. Apply WCAG/HIG versions from current authoritative sources.
