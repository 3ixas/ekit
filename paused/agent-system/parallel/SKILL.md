# Parallel

## Outcome

Complete, attributable results from every worker and one integrated decision or artifact.

## Method

Choose divide, compare, or race; define done predicate, shared brief, isolation, dependencies, and aggregation before dispatch; keep writers off shared state; collect successes, issues, blockers, and dropouts; judge with the declared rubric; verify the synthesis.

## Boundaries

Do not fan out routine work, use fixed model rosters, or let parallel outputs mutate the same branch or file.

Use the smallest relevant supporting capability. Report evidence, assumptions, and material limitations without narrating an internal skill chain.
